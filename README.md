### Introduction ###
The following directory contains scripts to generate a unlimited samples of defective images given a specific ROI of a specific operation. 

This is done using a large suite of normal good images, as well as a couple defective images (provided by EDMTs, PEs, etc.)

The output of these images are meant to be fed into Cognex or any other commercial defect detection modeling software. The goal is to provide more and easily obtainable samples without digging through BDP on especially low defect rate operations (<5%). Commercial modeling tools also perform better and converge better with a wide range of defective samples, even if they aren't neccessarily the most realistic.

Drawbacks: a model must be trained per operation/ROI. More than 0 defective images are still needed, preferably more than 10. The training cycle takes ~1 hr on the RTX5000 on Cognex204, ~12 hr on a i7 laptop cpu. The goal is that these downtime can be used to do other things rather than BDP digging (like defrosting meat).

Future work include: Using diffusion. I believe this is as powerful as GANs can be for this purpose. This architecture is limited to generating blob type defects, and the defects don't have relation to the artifacts in a good image, only to its expected position.

### Directory Structure ###
data/
    defect/             (defect images)
    defect_hard         (borderline defect images)
    good/               (normal images)
    inference_input/    (normal images of a certain operation)
outputs/
    v*/
        checkpoints/        intermediate models. mostly phased out
        defect_overlays/    most current model results, generated by overlay gan/unet python scripts. 
        fake_defects/       phased out model results on attempts to learn good features and defect features all at once
        fake_good/          phased out model results on attempts to learn only good features. Integrated into overlays
        All above folders include: checkpoints, analyses figures, visual sampled images across the epochs

Scripts:
train_defect_gan_v2-10      Phased out
train_good_gan_v1-6         Phased out but successful (core findings are integrated into overlay scripts)
defect_overlay_unet_v1-11   Earlier versions, ok
defect_overlay_gan_v12-15   Later versions, best

### Download Data ###
Download data/ from OneDrive for training
Download model.pt from OneDrive for inference (to generate images)

### Installation ###
Run:
    python -m venv .venv
    cd .venv
    pip install -r requirements.txt

### [BEST] Run Inference: Defect Overlay Gan v15 ###
Description: Given an op/ROI and a folder of good images, generate equal number of bad images
Have in root:
    /path/to/good/      (folder of normal images)
    /path/to/model.pt   (pytorch model of generator)
    inference_v15.py    (will generate a fake defect map and overlay over a normal img)    
Run:
    python inference_v15.py --good_dir /path/to/good --gen_ckpt /path/to/model.pt --out_dir /path/to/defect
Expect:
    /path/to/defect/    (folder of fake defect images, same number as normal)

### [BEST] Run Training: Defect Overlay Gan v15 ###
Description: Given an op/ROI, and a folder of good images & small number of defect images, generate a model to create more defective images. 
Input:
    data/defect         (preferably above 10 defect images)
    data/good           (preferably above 100 normal images)
Output:
    Generates above outputs at folder outputs/defect_overlays_cpu_v15/
    checkpoints (ckpt_100.pt is best one), defect maps, loss, sample images per epoch
Command:
    python defect_overlay_gan_v15.py        (change input/output directories in config section of code)

### Run Training: Generate good samples v6 ###
Description: Given an op/ROI, and a folder of good images, create more good images (rare use case)
Input:
    data/good           (preferably above 100)
Output:
    outputs/fake_good_v6/
    checkpoints, loss, samples, etc.
Command:
    python train_good_gan_v6.pyp            (change input/output directories in config section of code)
